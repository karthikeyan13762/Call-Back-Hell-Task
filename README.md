# CallbackHell

## Overview
This project demonstrates a classic example of callback hell using JavaScript. It showcases a countdown from 10 to 1, followed by a message that appears once the countdown completes. The goal is to illustrate the concept of deeply nested callbacks and the potential challenges associated with them.

## Features
- **Countdown Timer**: Counts down from 10 to 1, updating every second.
- **Callback Execution**: Executes a callback function after the countdown completes.
- **Dynamic Content Update**: Updates the content of the webpage with a styled message once the countdown finishes.

## Technologies Used
- **HTML5**: For the structure of the webpage.
- **CSS3**: For styling the page and the elements.
- **JavaScript**: For implementing the countdown logic and callback functionality.
